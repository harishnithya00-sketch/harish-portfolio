## 🌐 1-Click Step-by-Step GitHub Pages Deployment Guide

Your repository is already connected to:
`https://github.com/harishnithya00-sketch/harish-portfolio.git`

### Step 1: Commit and Push Code to GitHub
Run the following commands in your terminal:
```bash
git add .
git commit -m "feat: complete modern recruiter-ready portfolio website"
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to your repository on GitHub: **`https://github.com/harishnithya00-sketch/harish-portfolio`**
2. Click on **Settings** (⚙️ tab at top right).
3. In the left sidebar, click on **Pages**.
4. Under **Branch**, select `main` branch and folder `/(root)`.
5. Click **Save**.

🎉 Within 60 seconds, your portfolio will be live worldwide at:  
👉 **`https://harishnithya00-sketch.github.io/harish-portfolio/`**
